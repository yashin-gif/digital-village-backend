# Digital Village Backend

A FastAPI-based backend powering a Digital Village Management System designed to improve access to community information and essential village services.

## Overview

Digital Village aims to bring essential community services into one digital platform, helping people access information and interact with local services more efficiently.

## Key Features

* Secure user authentication and authorization
* Village community and family management
* Blood donation services
* Emergency assistance and welfare management
* Community institutions and local information
* Islamic educational content management
* Role-based access control
* Database-backed data management

## Technology Stack

* Python
* FastAPI
* SQLAlchemy
* PostgreSQL
* Alembic
* JWT Authentication
